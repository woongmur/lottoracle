# lottoracle

한국 로또 6/45 번호 추천기. **당첨번호 6개 + 보너스 1개를 5줄** 뽑아준다.
통계 필터(대한민국 로또 평균치)와 커뮤니티 민간속설을 둘 다 코드로 옮겨 놓았다.

---

## 먼저 읽을 것

로또는 매 회차 **독립적인 균등 무작위 추첨**이다. 지난 회차 번호, 이월수, 쌍둥이수,
징검다리, 꿈해몽, 미출현 기간 — 어느 것도 다음 회차 확률에 영향을 주지 않는다.
1등 확률은 조합을 어떻게 고르든 **1/8,145,060으로 고정**이고, 이 저장소의 코드도
그 숫자를 바꾸지 못한다.

이 프로그램이 실제로 하는 일은 두 가지다.

1. **모양 고르기** — 과거 당첨조합에서 흔했던 형태(합계, 홀짝, AC값, 구간 분포 등)에
   맞는 조합만 남긴다. 확률은 그대로지만, `1·2·3·4·5·6` 같은 조합은 피하게 된다.
   (같은 값이면 당첨 시 분배 인원이 적은 쪽이 유리하다는 정도의 실익은 있다.)
2. **속설 반영** — 이월수·징검다리·쌍둥이수·이웃수·꿈수·행운수 같은 속설을
   가중치로 구현한다. 근거는 없다. 재미와 기분을 위한 부분이고, 코드 안에도 그렇게 적혀 있다.

지출은 잃어도 괜찮은 금액까지만. 도박문제 상담 국번없이 **1336**.

## 설치 · 실행

파이썬 3.10+ 만 있으면 된다. **외부 라이브러리 없음.** 실제 당첨 데이터(1~1239회차)가
`data/draws.json` 에 들어 있어서 받자마자 바로 돌아간다.

```bash
git clone https://github.com/woongmur/lottoracle.git
cd lottoracle

python -m lottoracle gui       # 브라우저 GUI (http://127.0.0.1:8765 자동 오픈)
python -m lottoracle           # 터미널에서 추천 5줄
```

`pip install -e .` 를 하면 `lottoracle` 명령으로도 쓸 수 있다.

### 데이터 갱신

```bash
python -m lottoracle fetch                        # 동행복권 API에서 새 회차만 이어받기
python -m lottoracle import 회차별당첨번호.xlsx    # 동행복권 사이트에서 내려받은 엑셀 병합
```

동행복권 "회차별 당첨번호" 엑셀은 openpyxl 없이 표준 라이브러리로 직접 읽는다.

### GUI

| 탭 | 내용 |
|---|---|
| **추천** | 옵션(전략·행운수·기피수·꿈·띠·생일·속설·보정 범위·온도) → 색 공으로 5줄 + 분석 핵심 + 전형성 백분위 + 기분점수 |
| **통계** | 1,239회차 평균치, 홀짝·고저·AC·이월수 분포, 핫/콜드, 번호별 출현 막대, 자동 보정된 규칙 |
| **채점** | 조합 최대 10줄 × 회차 → 등수 판정. "사진 속 5조합 불러오기" 버튼으로 1239회차 대조 가능 |
| **백테스트** | 최근 N회차마다 직전 데이터만으로 추천 → 실제 당첨과 채점, 무작위·이론기대와 나란히 비교 |
| **회차** | 최근 회차 목록 (1등 당첨자 수·1게임당 당첨금 포함) |

### 터미널 출력 예시

```
1조합 [안정형 밸런스] :  5, 10, 18, 26, 33, 40  + 보너스 23
   [분석 핵심] 직전 1239회차 당첨수 33번을 이월수로 채포, 이웃수 26번으로 파동 확장,
              쌍둥이수 33번을 축으로 배치, 동형수 10·40 라인을 융합,
              합계 132(평균 138)·홀짝 2:4·AC 8로 평균치 안에 안착
   [지 표] 합계 132 · 홀짝 2:4 · 고저 3:3 · AC 8 · 끝수합 22 · 연속 0 · 구간 1-2-1-1-1 · 이월 2
   [구 간] 한 자리 5, 10번대 10·18, 20번대 26, 30번대 33, 40번대 40
   [속 설] 쌍둥이수 [33] / 이웃수(직전 ±1) [26] / 동형수 10·40 · 기분점수 91/100
```

## 명령어

| 명령 | 설명 |
|---|---|
| `python -m lottoracle` | 추천 5줄 (기본 명령, `recommend` 생략 가능) |
| `python -m lottoracle gui` | 브라우저 GUI (`--port`, `--no-browser`) |
| `python -m lottoracle stats` | 과거 회차 평균치 · 핫/콜드 번호 |
| `python -m lottoracle grade 11 13 22 32 36 45 --draw 1239` | 조합 채점 — 6개 단위로 여러 줄 가능 |
| `python -m lottoracle backtest --rounds 52` | 최근 52회차 백테스트 (모델 vs 무작위 vs 이론기대) |
| `python -m lottoracle check 3 10 18 25 34 44` | 내 조합이 평균치 안에 드는지 검사 |
| `python -m lottoracle fetch` | 동행복권 API에서 새 회차 수집 |
| `python -m lottoracle import 파일.xlsx` | 엑셀/CSV를 캐시에 병합 |

### 추천 옵션

```bash
python -m lottoracle \
  --lines 5 \                 # 줄 수
  --seed 20260905 \           # 시드 고정 (같은 시드 = 같은 번호)
  --lucky "7 13" \            # 행운수 — 가중치 상승
  --avoid 4 \                 # 기피수 — 아예 제외 (4는 죽을 사, 라고들 한다)
  --dream 돼지꿈 \             # 꿈해몽 번호
  --birthday 1990-05-21 \     # 생일수
  --zodiac 1990 \             # 띠수 (해 또는 '말' 처럼 띠 이름)
  --strategy carryover \      # 특정 전략만 사용 (여러 번 지정 가능)
  --no-folklore \             # 속설 전부 끄고 통계 필터만
  --coverage 0.8 \            # 실데이터 보정 범위 (0.5 빡빡 ~ 0.99 느슨)
  --manual-rules \            # 자동 보정 대신 전략별 수동 규칙
  --candidates 40 \           # 줄당 후보 수 — 많을수록 '전형적인' 조합
  --temperature 1.0 \         # 선택 온도 — 낮을수록 가장 흔한 모양만
  --max-overlap 3             # 줄 간 최대 중복 번호 수
```

네트워크가 막힌 환경이면 `--offline` 을 붙이거나, CSV로 데이터를 직접 넣는다.

```bash
# 헤더 없이: 회차,n1,n2,n3,n4,n5,n6,보너스[,날짜]
python -m lottoracle --csv my_draws.csv
```

## 통계 필터 — '대한민국 로또 평균치'

`lottoracle/filters.py` 의 `Ruleset` 기본값. 실제 당첨조합에서 흔한 구간이다.

| 항목 | 기본 허용 범위 | 근거 |
|---|---|---|
| 번호 합계 | 100 ~ 175 | 이론 기대값 6×23 = **138** |
| 홀수 개수 | 2 ~ 4 | 3:3이 최빈 |
| 저구간(1~22) 개수 | 2 ~ 4 | 3:3이 최빈 |
| AC값 | 7 이상 | 당첨조합 최빈 8 (최대 10) |
| 연속수 | 최대 2연속, 연속쌍 1개 | 3연속 이상은 드묾 |
| 한 구간 집중 | 최대 3개 | 5구간(1~9/10~19/20~29/30~39/40~45) |
| 끝수합 | 15 ~ 35 | |
| 같은 끝수 | 최대 2개 | |
| 번호 폭(최대−최소) | 20 이상 | |
| 이월수(직전 회차 중복) | 0 ~ 2 | 전략별로 다름 |

조건을 만족하는 조합을 못 찾으면 `Ruleset.relaxed()` 로 단계적으로 완화하고,
그 사실을 출력에 `(규칙 N단계 완화)` 로 표시한다.

**AC값**이란: 6개 번호로 만들 수 있는 15개 차이값 중 서로 다른 값의 개수에서 5를 뺀 수.
등간격 조합(4·11·18·25·32·39)은 AC가 낮아 걸러진다.

## 고도화 — 실데이터 보정 · 전형성 점수 · 백테스트

### 자동 보정 (`model.calibrate`)
1~1239회차 실제 당첨조합의 백분위로 `Ruleset` 범위를 만든다. `coverage=0.8` 이면
합계·끝수합·번호폭은 가운데 80%를 덮는 범위, 홀짝·고저·AC·연속수는 양쪽 10% 꼬리를
잘라낸 범위가 된다. 실데이터 요약:

| 항목 | 실측 (1,239회차) |
|---|---|
| 당첨번호 합 평균 | **138.3** (이론 138) |
| 홀수 개수 | 3개 33% · 2개 23% · 4개 26% |
| AC값 | 8이 35%로 최빈, 7~10이 85% |
| 연속수 포함 | 51.7% |
| 이월수 | 1개 42% · 0개 39% · 2개 17% |

### 전형성 점수 (`model.typicality`)
합계·홀짝·고저·AC·끝수합·연속수·구간 패턴·이월수·번호폭·**위치별 번호 분포**(1번째 공은
대개 1~10, 6번째 공은 대개 35~45)의 경험 분포에서 라플라스 평활 로그가능도를 합산한다.
생성기는 줄마다 후보를 `--candidates` 개 모아 이 점수로 소프트맥스 선택하고, 과거
당첨조합들의 점수 분포 안에서의 **백분위**를 같이 보여준다. `1·2·3·4·5·6` 은 백분위 0.

### 백테스트 (`backtest.run`)
회차 N마다 N-1까지의 데이터만으로 추천을 만들어 실제 N회차와 채점한다. 무작위 5줄과
이론 기대값(5등 1/45, 4등 1/733, 3등 1/35,724 …)을 나란히 놓는다. 시드를 바꿔 가며
돌리면 모델과 무작위가 앞서거니 뒤서거니 한다 — **이 도구가 확률을 바꾸지 못한다는
증거**이고, 그래서 넣어 두었다.

### 사진 속 조합의 실제 성적
커뮤니티 사진(1238회차 기준 예측)을 1239회차 실제 번호 `11 13 22 32 33 36 + 8` 로 채점하면
3조합 `11 13 22 32 36 45` 가 **5개 일치 = 3등(약 150만원)** 이다. GUI 채점 탭의
"사진 속 5조합 불러오기"로 확인할 수 있다. 백테스트를 돌려 보면 그게 왜 운인지도 보인다.

## 민간속설 — `lottoracle/folklore.py`

사진 속 "공식"과 커뮤니티에서 도는 속설을 전부 옮겨 놓았다. `--no-folklore` 로 끌 수 있다.

| 속설 | 구현 |
|---|---|
| **이월수** | 직전 회차 당첨번호를 전략별로 0~2개 강제 포함 |
| **징검다리** | 직전 회차 **보너스볼**을 다음 조합에 고정 |
| **이웃수** | 직전 회차 번호 **±1** 에 가중치 (`neighbor_weight`) |
| **쌍둥이수** | 11·22·33·44 에 가중치 |
| **궁합수** | 과거에 자주 같이 나온 번호쌍을 뽑을 때마다 재계산해 가중 |
| **동형수** | 끝수가 같은 번호 묶음(3·13·23)을 태그로 표시 |
| **볼 색상 균형** | 노랑1~10 / 파랑11~20 / 빨강21~30 / 회색31~40 / 초록41~45 — 한 색 최대 3개, 최소 3색 |
| **용지 모양** | 마킹 용지 7열 격자에서 직선·대각선으로 죽 그은 모양 회피, 뭉친 칸 제한 |
| **꿈해몽수** | 돼지·용·조상·똥·불·물·뱀·호랑이·아기·돈·무지개·장례·이빨·산·비·바다 |
| **생일수 / 띠수** | 생년월일·띠에서 번호 도출 (1990년생 → 말띠 → 7·19·31·43) |
| **행운수 / 기피수** | 가중치 상승 / 완전 제외 |
| **기분점수** | 위 항목이 몇 개 걸렸는지로 0~100 점수. **확률과는 아무 상관 없다** |

## 5가지 전략 (5줄이 각각 다른 성격)

`lottoracle/strategies.py`

| 키 | 이름 | 성격 |
|---|---|---|
| `balance` | 안정형 밸런스 | 평균치 정중앙. 합계·홀짝·고저·구간 전부 최빈값 |
| `carryover` | 이월수 채포형 | 직전 당첨수 2개를 이월수로 고정 |
| `bridge` | 징검다리 저격형 | 직전 보너스볼 + 쌍둥이수 조합 |
| `variant` | 변칙 조준형 | 이월 1개 + 장기 미출현수로 허리 |
| `aggressive` | 공격형 라인업 | 이월수를 끊고 저빈도·장기미출현 위주 롱샷 |

## 구조

```
lottoracle/
  data.py        회차 수집(동행복권 API) · JSON 캐시 · CSV/xlsx 입력(표준 라이브러리)
  metrics.py     합계 / 홀짝 / 고저 / AC값 / 연속수 / 끝수 / 구간 등 지표
  filters.py     Ruleset — 평균치 필터와 단계적 완화
  stats.py       빈도 · 최근 출현 · 미출현 기간 · 궁합수 · 회차 평균치 요약
  model.py       실데이터 백분위 보정(calibrate) · 전형성 점수(typicality)
  folklore.py    민간속설 (색상·용지·꿈·띠·행운수 …)
  strategies.py  5가지 전략 정의
  generator.py   가중 비복원 추출 → 후보 풀 → 전형성 소프트맥스 선택 → 줄 간 중복 제한
  backtest.py    등수 판정(grade) · 백테스트(run)
  explain.py     '[분석 핵심]' 코멘트 생성
  engine.py      CLI/GUI 공용 서비스 계층
  web.py         http.server 기반 GUI 서버 + JSON API
  gui.html       GUI 화면 (단일 파일, 외부 리소스 없음)
  cli.py         명령줄 인터페이스
data/
  draws.json               1~1239회차 실제 당첨 데이터 (fetch/import 로 갱신)
  source/lotto_1-1239.xlsx 동행복권 원본 엑셀
tests/           단위 테스트 (합성 데이터 + 실데이터)
```
